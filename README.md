# Food Store — Programación II (UTN)

Trabajo Práctico Integrador de Programación II: sistema de gestión de pedidos de comida con Java 21, POO, JDBC puro y menús de consola.

## Alcance

- `Categoria` y `Producto`: persistencia por JDBC.
- `Usuario`, `Pedido` y `DetallePedido`: colecciones en memoria.
- Proyecto sin Maven, Gradle, JPA ni Hibernate.

Este repositorio es exclusivo de Programación II. Bases de Datos I utiliza el mismo dominio de negocio en un repositorio independiente.

**Estado:** inicialización del proyecto. Las funcionalidades CRUD, la conexión JDBC y los menús están pendientes de implementación y pruebas.

La documentación de decisiones y pruebas se irá completando en `docs/bitacora.md`.
